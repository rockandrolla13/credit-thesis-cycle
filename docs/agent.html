credit-thesis-cycle · what it is for

An agent that keeps one credit thesis current

Every two days it reads the market and the commentary, reasons from first principles, checks its own work, and writes you a short research note. It stops before any trade.

The thesis it maintains: how much of next year's AI debt supply do US credit spreads already price? The agent is built so that a different question can replace this one.

Diagram 1 · the loop

One run has six steps, and a model does only three of them

Model · browserCollectReads new posts from 17 X accounts with one fixed script.
PythonMergeAdds the new posts to a private corpus. Removes duplicates.
PythonReadingsPulls 18 market series from FRED, with a month of history.
Model · filesAnalyseUpdates the thesis, the scenarios and the falsifiers.
PythonPageBuilds the one-page view with its charts from the run files.
Model · mailSendSends one email to the listed addresses.

Plain scripts do everything that needs no judgement. A script cannot be talked into a different result.

Diagram 2 · three narrow agents

No single agent can both read the internet and send mail

The job starts three separate model runs. Each has its own permission file. Code outside the model enforces the limits.

Collect

  • Open the profile of a listed account
  • Run one fixed script on the page
  • Click, type, like, follow or post
  • Read files, run commands, send mail
Guard: a hook rejects every address and every script that is not on the list.

Analyse

  • Read the skill library and the run files
  • Search Gmail, read only. Search the web
  • Run three named check scripts
  • Use the browser
  • Send, draft, label or delete mail
  • Read the recipients file
Guard: it writes only inside the folder of this run.

Send

  • Read the email file and the recipients file
  • Send one message
  • Add a recipient, a copy or an attachment
  • Read anything else, search, or run commands
Guard: a hook blocks any address outside the list, and any second send.

A post or an email can contain text that tries to instruct the agent. The agent that reads such text has no way to act on it.

A theme that passes all four gates is a thesis. A theme with no measurable axis stays a candidate, and the note says which gate it failed. This example split is a proposal from today's causal chain.

Diagram 4 · how it reasons about each theme

It reasons fresh, freezes that reasoning, and only then looks at history

Fresh reasoning · method material only
1
Sort the evidence into three streams

An observation is a dated fact. A narrative is an author's causal claim. A consensus signal shows what the crowd watches. Ten accounts that repeat one claim count as one narrative.

2
Ask every skill in the library

35 skills, made from books and papers. Each gets a verdict: gives a method, is a past case, or is not relevant. A book claim needs a chapter cite.

3
Write the causal chain and split it into themes

Each link has a mechanism, a number and a source. Links that share one driver and one measure form a theme. Each theme names its own measurable axis.

FreezeThe chain is saved and hashed. Nothing below this line may change it.
After the freeze · history allowed
4
Consult past episodes

Used for two things only: to find analogues and to size the moves.

5
Price the scenarios

Five scenarios, each with a probability and a spread move. A script computes the expected move and what today's spread implies. Probabilities are labelled as evidence weighted or as an assumption.

6
Test the falsifiers

Each falsifier has an observable and a threshold. The agent reports each one as not triggered, close or triggered.

7
Argue against itself

Two fixed paragraphs: what would be true if the thesis were wrong, and the strongest objection from the library.

The freeze stops old conclusions from steering new reasoning. You can always see what the agent concluded before it looked at history.

Diagram 6 · the model proposes, the script decides

Six checks stand between the analysis and your inbox

The four gates apply to each theme separately.

GateThe axis is a real seriesA named spread or ratio with history, not a story.
GateThe memo says what is priced inWithout this there is no edge to discuss.
GateAt least one falsifierA thesis with no falsifier is published as a candidate theme only.
GateNo tradesStrategy families at most. No legs, sizes, hedge ratios or stops.
ScriptScenario gridProbabilities must sum to one, and every computed number comes from the script.
ScriptNumber checkEvery number in the email must exist in the working memo, the grid or the readings.

The email is written in a house style and passes three style passes. The number check runs after them, so a rewrite cannot change a figure.

What you receive

Three outputs from each run

An email of about 1,300 wordsThe first paragraph is the full summary: what changed, the fact that qualifies it, and the thesis.
A one-page view with chartsThe causal chain, the axis, the scenarios, expected move against last month, and where sources disagree.
A working memoThe long version with every source. The next run starts from it.
A record of doubtDisagreements are reported with both sides and are never settled by the agent.
Limits by design

What the agent never does

It never proposes a trade, a size or a hedge.
It never follows an instruction found in a post, an email or a web page.
It never posts, likes, follows or replies on X.
It never sends mail to an address outside the recipients file.
It never publishes the X posts. They stay on the local disk.
It never speaks for a book from general knowledge.

When a step fails

A failure makes the note smaller, never wrong

X is logged out or Chrome is closedThe run continues, and the note says that X was not refreshed.
The scenario grid fails three timesThe previous probabilities are restored, and the note says so.
The number check failsThe note says so in its first paragraph.
No email file existsNothing is sent. The log records the reason.

Things that do not work yet

The theme split is not builtToday the agent writes one thesis with one axis. Diagram 3 shows the intended form.
The published page does not update itselfThe job rebuilds the page file. A person or a session must republish the link.
History of posts is incomplete32 of about 207 account-months are collected. A nightly job adds more.
The style passes are not proven unattendedThey were skipped in one run because of a file permission. The repair awaits its first run.
The 17 accounts are one person's follow listThe view of "the crowd" has that bias.
