# Step 1: the weakness and the changes that matter

The weakness: step 1 is a list of topics to discuss. It has no rule for how a theme forms, no test, and no memory.

## The five changes that matter most

1. **Turn each input into a lens card.** One question, the series that answer it, a method from a named skill, and today's reading. Example for policy: "does the curve already hold the path?"
2. **Give theme formation a rule.** A theme needs findings from at least two inputs that agree, and one mechanism that connects them. A finding from one input is an observation only.
3. **Measure consensus.** Alaph says to monitor whether a view became consensus. I would count it: facts on one side, attention on the other. Strong facts with little attention rank first.
4. **Give each theme a falsifier and a verdict date.** Today a theme cannot fail, so it never leaves the list.
5. **Keep a ledger and score it.** Each theme is born, grows, becomes crowded, fails or retires. After the verdict date, record if it held. Step 1 then learns which inputs and sources lead.

The proposal has four more: three evidence streams, an objection paragraph, a theme card with winners and losers, and a list of blind spots in each run.

## What stays out

Pricing. Step 1 proposes a measure for each theme and stops. "What is priced in" and the scenarios belong to step 2.

## How we would know it improved

- Every theme has a falsifier.
- Every theme rests on two or more inputs.
- Attention at the birth of a theme is recorded.
- Past themes get a verdict.
