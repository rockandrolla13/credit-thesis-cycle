# Glossary: Forecasting Expected Returns in the Financial Markets (Satchell, ed.)

Symbols change meaning between chapters. Each entry names its chapter.

**Absolute view / relative view** — a return level for one asset, versus a return difference between assets. A relative row of P sums to 0 (Ch 2)
**Aggression (strategy aggression)** — the size of the model score S(0). A score of 1.0 means an expected return of +1 standard deviation to the horizon (Ch 10, Ch 11)
**Ambiguity aversion** — aversion to situations where no probabilities can be assigned. The basis of maximin expected utility (Ch 8)
**Amihud illiquidity measure** — monthly average of absolute daily return over dollar volume (Ch 9, eq. 9.2)
**Belief vector / belief matrix D** — one homogeneous inequality on expected returns. The stack of all of them (Ch 4)
**Blom approximation** — inverse-normal formula for the centroid of a complete sort (Ch 4)
**Centroid** — centre of mass of the cone of consistent returns under a radially symmetric measure. It replaces the expected-return vector (Ch 4)
**Conditional asset pricing** — models that let expected returns, risk and volatility vary over time (Ch 1)
**Confidence level (C_k)** — a user-stated 0% to 100% confidence in view k, from which Idzorek solves omega_k (Ch 2)
**Consistent cone Q** — all expected-return vectors that satisfy the investor's ordering beliefs (Ch 4)
**Constant weight model** — a composite with fixed sub-model weights along the whole efficient frontier (Ch 10)
**CVaR** — average loss beyond a threshold. Optimized by linear programming on a Monte Carlo set (Ch 5)
**Data mining, naive / sophisticated** — searching for patterns without, or with, a correction for the number of searches (Ch 1)
**Decay beta (b)** — exponential decay rate of the IC. Half-life is Ln(2)/b (Ch 10)
**Difference asset** — an asset that expresses one ordering belief, such as S1 minus S2 (Ch 4)
**Efficient markets view of predictability** — predictability reflects time-varying required returns, not mispricing (Ch 1)
**Empirical Bayes prior** — a prior whose hyperparameter is set from the sample (Ch 6, Ch 7)
**Equilibrium excess returns (Pi, pi)** — returns implied by reverse optimization from market weights (Ch 2, Ch 3)
**Error-maximization** — optimizers overweight assets with unrealistically high estimates (Ch 2, Ch 8)
**Estimation risk** — dispersion of the option price left by an estimated volatility (Ch 6)
**Exploitable inefficiencies view** — predictability reflects frictions or cognitive bias and can be traded (Ch 1)
**Forecast error (FE)** — ex ante expected return minus later realized return (Ch 8)
**Half-life** — the period over which half of a model's forecasting value is used up (Ch 10)
**Hedge portfolio** — long one extreme sorted portfolio and short the other (Ch 9)
**Implied confidence level** — actual tilt divided by the tilt under 100% confidence (Ch 2)
**Implied volatility as prior** — the option market's volatility, used as the inverted-gamma prior with weight t' (Ch 7)
**Information coefficient (IC)** — cross-sectional correlation of forecasts with later returns (Ch 10, Ch 11)
**IC_t versus cumulative IC** — the IC for period t-1 to t, versus the IC of cumulative returns from 0 to t. Equal only at t = 1 (Ch 10)
**Joint hypothesis** — any efficiency test also tests a model of equilibrium returns (Ch 1)
**Kelly (log optimal) bet** — the bet that maximizes expected log wealth. Stake fractions equal own probabilities (Ch 12)
**$1 Kelly bet** — a derivative that costs $1 and pays (q/p)(1+r) (Ch 12)
**LIQ** — mimicking liquidity factor: liquid-minus-illiquid return from a median split, rebalanced yearly (Ch 9)
**Linear factor model as local linearization** — exposures are partial derivatives at a moving point, so they must be recalculated (Ch 5)
**Local normality** — returns are normal over short periods or given a state of the world (Ch 5)
**Loss gain ratio** — CVaR divided by upside potential (Ch 5)
**Maximin expected utility** — choose the weight that maximizes the minimum expected utility across scenarios (Ch 8)
**Mixture of normals** — m regimes, each multivariate normal with a probability. The authors' standard forecast form (Ch 5)
**Momentum / reversals** — past winners keep winning (3-12 months), or later lose (weekly, monthly, 4-5 years) (Ch 1)
**Omega (view uncertainty)** — diagonal covariance of view errors. Omega = 0 means certainty (Ch 2, Ch 3)
**Optimal horizon (t*)** — the holding period that maximizes annualized after-cost return (Ch 10, Ch 11)
**Optimism (h_i)** — an agent's odds of the up state divided by the risk-neutral odds (Ch 13)
**P and Q (q)** — the matrix that maps views to assets, and the vector of view returns (Ch 2, Ch 3)
**Partial IC (PIC)** — forecasting power not explained by correlation with other information. COR^-1 IC (Ch 10, Ch 11)
**Permutation distance** — a measure of how far a proposed ordering is from the true one (Ch 4)
**Portfolio sort** — a belief about the order of expected returns: complete, sector, partial or multiple (Ch 4)
**Predictive density** — the density of a not-yet-observed option price, random in both price and volatility (Ch 7)
**Prospector** — an investor who follows prospect theory, with loss aversion lambda (Ch 13)
**Relative liquidity measure** — the authors' size-free version of Amihud: turnover in the denominator, in logs (Ch 9, eq. 9.3)
**Relative predictability** — one group of stocks predictably beats another, whatever the market does (Ch 1)
**Reverse optimization** — Pi = lambda Sigma w_mkt (Ch 2, eq. 2.1)
**Risk-neutral probability (p_u, pi)** — a pricing weight, not the market's belief (Ch 12, Ch 13)
**Risk versus uncertainty** — probabilities can be assigned, versus cannot (Ch 8)
**Shrinkage** — pulling sample estimates toward a model-based prior (Ch 8)
**Smart turnover constraint** — a forecast-error constraint written against initial weights (Ch 8)
**SOCP** — second-order cone programming. A linear objective with linear and cone constraints (Ch 8)
**Spurious regression** — a "significant" slope between independent persistent series (Ch 1)
**Stambaugh bias** — small-sample slope bias when predictor shocks correlate with return shocks (Ch 1)
**Stochastic discount factor (m)** — the variable that prices all assets through E{m(1+r)|Omega} = 1 (Ch 1)
**Tau** — the scalar that scales the equilibrium covariance in Black-Litterman. Guidance on its value conflicts (Ch 2, Ch 3)
**Valuation ratio** — a cash flow measure divided by price, such as dividend/price (Ch 1)
**View portfolio variance** — p_k Sigma p_k'. The He-Litterman basis for omega_k (Ch 2)
**w_100%** — portfolio weights under complete certainty in the views (Ch 2)
